# Package index

## Palettes

Getting colours out of a palette, and finding out what is available.

- [`energypal()`](https://optimal2050.github.io/energypal/reference/energypal.md)
  : Energy colour palette
- [`energypal_info()`](https://optimal2050.github.io/energypal/reference/energypal_info.md)
  : Available energy palettes
- [`energypal_show()`](https://optimal2050.github.io/energypal/reference/energypal_show.md)
  : Plot energy palettes
- [`energypal_table()`](https://optimal2050.github.io/energypal/reference/energypal_table.md)
  : Flatten a palette into a table

## Matching data labels

Resolving the source labels real datasets use onto palette entries.

- [`energypal_colors()`](https://optimal2050.github.io/energypal/reference/energypal_colors.md)
  [`energypal_colours()`](https://optimal2050.github.io/energypal/reference/energypal_colors.md)
  : Colours for a vector of data labels
- [`energypal_match()`](https://optimal2050.github.io/energypal/reference/energypal_match.md)
  : Match data labels to palette entries

## Your own palettes

A named colour vector is a palette; save it, edit the YAML, load it
back.

- [`energypal_create()`](https://optimal2050.github.io/energypal/reference/energypal_create.md)
  : Build a palette from a named colour vector
- [`energypal_write()`](https://optimal2050.github.io/energypal/reference/energypal_write.md)
  : Write a palette to a YAML file
- [`energypal_register()`](https://optimal2050.github.io/energypal/reference/energypal_register.md)
  : Register a user palette for this session
- [`energypal_spec()`](https://optimal2050.github.io/energypal/reference/energypal_spec.md)
  : Load a palette specification
- [`energypal_validate()`](https://optimal2050.github.io/energypal/reference/energypal_validate.md)
  : Validate a palette specification
- [`energypal_validate_families()`](https://optimal2050.github.io/energypal/reference/energypal_validate_families.md)
  : Check the family structure of the built-in palettes
